# FarLook · 远眺一下

一个轻量、完全本地运行的 macOS 菜单栏休息提醒工具：连续使用电脑 **30 分钟**后，提醒你远眺 **30 秒**。

[English](README.en.md) · [参与改进](CONTRIBUTING.md) · [更新记录](CHANGELOG.md)

## 下载与运行

在本仓库的 **Releases** 下载 `FarLook-v0.2.0-macOS-arm64.zip`，解压后将“远眺一下.app”拖到“应用程序”，双击打开。运行时菜单栏会出现眼睛图标和剩余时间，没有常驻 Dock 图标。

- 当前支持 **Apple Silicon（M 系列芯片），macOS 13 及以上**。
- 已在 macOS 26.3.1 上构建并做基本界面检查。其他系统、全屏和多显示器行为仍需更多反馈。
- 当前版本采用本地临时签名，**未获 Apple 公证**。若系统阻止打开，可先检查源代码并自行构建，或在 macOS 的“隐私与安全性”中按系统提示处理；请勿关闭 Gatekeeper。
- 当前需手动启动，未设置开机自启。

## 连续使用怎样定义？

默认规则是 **无键鼠操作达到 2 分钟，就重置本轮计时**。

| 情况 | 计时行为 |
| --- | --- |
| 持续操作，或静止不足 2 分钟 | 计入本轮 30 分钟 |
| 无操作达到 2 分钟 | 本轮清零，等待下一次操作 |
| 锁屏、系统睡眠、屏幕休眠、切换用户 | 本轮清零 |
| 连续使用满 30 分钟 | 弹出可推迟的休息提醒 |
| 点击“开始 30 秒休息” | 倒计时 30 秒，结束时播放可关闭的提示音 |
| 点击“5 分钟后提醒” | 延后提醒；若其间无操作满阈值，仍按长暂停规则清零 |
| 休息结束 | 等待下一次操作开始新一轮 |

菜单中可选择无操作 2、5、10 分钟重置，或只在锁屏／睡眠及休息后重置。改变规则、恢复提醒或重新打开应用会开始新一轮。

**长文阅读与视频：** 无操作不等于离开屏幕。默认设置下，静止阅读或看视频超过 2 分钟也会清零；经常遇到这种情况，可改用更长阈值或仅锁屏／睡眠重置。

倒计时只记录时间经过，不能确认是否远眺。本工具提供休息提醒，不测量注视时间，也不声称具有已验证的医学疗效。

## 隐私

不联网、不使用摄像头、不读取输入内容、不记录正在使用的应用、不保存使用历史。只读取系统输入空闲时长与会话／睡眠状态，在本机保存判定规则和提示音偏好。无需辅助功能、屏幕录制或摄像头权限。

## 从源码构建

安装 Xcode 或 Xcode Command Line Tools 后，在项目目录执行：

```sh
zsh scripts/test.sh
zsh build.sh
open build/远眺一下.app
```

无第三方运行依赖，默认生成 arm64 应用。图标 PNG、ICNS 和生成记录位于 `assets/`。构建脚本会用 macOS 自带的 `sips` 和 `iconutil` 重新生成图标。

计时每秒采样一次，可能有约 1 秒显示／触发误差。应用未运行或退出时无法提醒。锁屏使用系统通知约定，并辅以公开的睡眠及会话通知；计时模型检查不能替代所有真实系统场景的测试。详见 [验证记录](VERIFICATION.md)。
